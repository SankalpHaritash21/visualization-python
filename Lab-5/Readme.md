# Use different data visualization techniques to transform data

## Objective

    - Understand the importance of data visualization in transforming raw data into meaningful insights
    - Apply different visualization techniques using Python libraries (Matplotlib, Seaborn, Plotly)
    - Interpret data trends, distributions, and relationships through visualizations.

## Prereqiuisites

    ```
        pip install matplotlib seaborn plotly pandas
    ```

## Why Data Visualization?

    transformation of raw numbers into interpretable patterns
